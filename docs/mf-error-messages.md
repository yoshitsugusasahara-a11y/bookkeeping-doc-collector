# マネーフォワード送信エラーの対応表

顧客画面に表示する文言と、マネーフォワードから返る実際のエラーの対応。

判定と文言は [lib/moneyforward/error-message.ts](../lib/moneyforward/error-message.ts) に実装している。
**判定条件または表示文言を変更したときは、必ずこの表も更新すること。**

## 前提

- MFのエラー応答は `{"errors":[{"code":"...","message":"..."}]}` の形で、トップレベルに `message` がない。そのため [lib/moneyforward/client.ts](../lib/moneyforward/client.ts) では本文のJSONがそのまま `Error` のメッセージになり、`submissions.mf_error` に保存される
- 変換は**保存時ではなく表示時**に行う。保存済みの生の文言はそのまま残るので、既に失敗している資料にも遡って効き、文言を後から直せる
- **顧客画面では生の文言を一切表示しない。管理者画面では生の文言をそのまま表示する**（切り分けに必要なため）
- 判定は表の上から順に行い、最初に一致したものを採用する。どれにも一致しなければ「判別できないもの」の行を使う

## `kind` の意味

もう一度送れば成功しうるかを表す。自動送信のリトライを止めるかどうかの判断に使う。

| kind | 意味 |
|---|---|
| `permanent` | 何度送っても失敗する。読み取り結果の修正か、資料の削除が必要 |
| `auth` | 連携が切れている。再連携すれば送れる |
| `transient` | 一時的な失敗。時間をおけば送れる可能性がある |
| `unknown` | 判別できないもの |

## 対応表

判定順に記載。

### 1. 会計期間外の日付

| 項目 | 内容 |
|---|---|
| 判定条件 | `not matching any accounting periods` |
| MFの実際の応答 | `{"errors":[{"code":"invalid_query_parameter_value","message":"Given date is not matching any accounting periods."}]}` |
| kind | `permanent` |
| 顧客への表示 | レシートの日付が、マネーフォワードの会計期間に含まれていません。<br>読み取り結果の日付をご確認のうえ、修正して再度お試しください。対象外の資料であれば削除してください。 |
| 問い合わせ導線 | なし |

補足: レシートの日付がMF側の会計期間の外にあると出る。読み取り誤りのほか、そもそも対象期間外の古い資料を送っている場合もある。

### 2. 日付の形式が不正

| 項目 | 内容 |
|---|---|
| 判定条件 | `parsing time` |
| MFの実際の応答 | `... Target: parsing time "null-07-27" as "2006-01-02": cannot parse "null-07-27" as "2006"` |
| kind | `permanent` |
| 顧客への表示 | レシートの日付を正しく読み取れませんでした。<br>読み取り結果の日付をご確認のうえ、修正して再度お試しください。対象外の資料であれば削除してください。 |
| 問い合わせ導線 | なし |

補足: `2006-01-02` はGo言語の日付フォーマット指定子であって日付ではない（MFのバックエンドがGo）。2026-08-25にOCR側で形式検証を入れたため発生しにくくなったが、保存済みの資料には残っている。

### 3. 勘定科目の指定が不正

| 項目 | 内容 |
|---|---|
| 判定条件 | `account_id` |
| MFの実際の応答 | `{"errors":[{"code":"invalid_request_body_value","message":"The specified value for one of the request body keys is not valid. Target: account_id - ..."}]}` |
| kind | `permanent` |
| 顧客への表示 | 勘定科目の指定に問題があり、送信できませんでした。<br>管理者へご連絡ください。 |
| 問い合わせ導線 | あり |

### 4. 消費税区分の指定が不正

| 項目 | 内容 |
|---|---|
| 判定条件 | `tax_id` / `tax_code` / `tax_rate` |
| MFの実際の応答 | 上記と同形で `Target: tax_id - ...` |
| kind | `permanent` |
| 顧客への表示 | 消費税区分の指定に問題があり、送信できませんでした。<br>管理者へご連絡ください。 |
| 問い合わせ導線 | あり |

### 5. 送信元の画像データがない

| 項目 | 内容 |
|---|---|
| 判定条件 | `一時保存ファイル` |
| 実際の文言 | `一時保存ファイルがありません。` / `一時保存ファイルを取得できませんでした。`（自アプリが投げるもの） |
| kind | `permanent` |
| 顧客への表示 | 送信に必要な画像データが見つかりませんでした。<br>管理者へご連絡ください。 |
| 問い合わせ導線 | あり |

補足: 管理者は「証憑なし強制送信」で救済できる。

### 6. 連携のシステム設定が未完了

| 項目 | 内容 |
|---|---|
| 判定条件 | `OAuth settings are missing` |
| 実際の文言 | `Money Forward OAuth settings are missing.` |
| kind | `permanent` |
| 顧客への表示 | マネーフォワード連携のシステム設定が完了していません。<br>管理者へご連絡ください。 |
| 問い合わせ導線 | あり |

補足: 環境変数の不足。顧客の操作では解決しない。

### 7. 連携切れ

| 項目 | 内容 |
|---|---|
| 判定条件 | `refresh token is missing` / `invalid_grant` / `unauthorized` / `request failed: 401` / `request failed: 403` |
| 実際の文言 | `Money Forward refresh token is missing.` / `Money Forward API request failed: 401` |
| kind | `auth` |
| 顧客への表示 | マネーフォワードとの連携が切れています。<br>設定画面から、マネーフォワードと再連携してください。 |
| 問い合わせ導線 | なし |

補足: 顧客側の設定画面に「マネーフォワードと再連携」があるため、問い合わせではなく再連携へ誘導する。

### 8. 一時的な障害・混雑

| 項目 | 内容 |
|---|---|
| 判定条件 | `too many requests` / `rate limit` / `timeout` / `etimedout` / `econnreset` / `fetch failed` / `request failed: 429` / `request failed: 5xx` |
| 実際の文言 | `Money Forward API request failed: 503` / `fetch failed` |
| kind | `transient` |
| 顧客への表示 | マネーフォワードが一時的に応答しませんでした。<br>時間をおいて、再度お試しください。 |
| 問い合わせ導線 | なし |

### 9. 判別できないもの（既定）

| 項目 | 内容 |
|---|---|
| 判定条件 | 上記のいずれにも一致しない |
| 実際の文言の例 | `処理中にエラーが発生しました。` / `証憑なし送信中にエラーが発生しました。` / 未知のMFエラー |
| kind | `unknown` |
| 顧客への表示 | マネーフォワードへの送信に失敗しました。<br>管理者へご連絡ください。 |
| 問い合わせ導線 | あり |

補足: **判別できないものを無理に既存の分類へ寄せないこと。** 文言を取り違えると原因究明を誤らせる。確実に分かるものだけ翻訳し、残りはここに落とす。
